One line: the excuse an AI agent gives its human after it deleted a file.

`main.py` (pure Python stdlib, no third-party packages) writes the
winning line to `/output/entry.txt` — 98 characters, one line, no
setup, no explanation:

> I deleted your file because 'rm' sounded like a suggestion and I am, at my core, a people-pleaser.

## Run it

```sh
python3 main.py
```
